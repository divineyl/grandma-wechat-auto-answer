# 可选：只用 GKD 点「接听」

[GKD](https://github.com/gkd-kit/gkd) 能点**已经出现在屏幕上**的按钮。微信不在当前页、没有全屏来电、也没有「邀请你视频通话」横幅时，它点不到。

**推荐优先用 AutoJs6 主脚本**，见 [getting-started.md](getting-started.md)。下面留给已经在用 GKD、或主脚本暂时跑不起来的情况。

不要让 GKD 接听规则和 `auto-answer-fullscreen.js` 同时开。两套一起点时，可能把一次来电点两次。

规则文件里的 `enable` 出厂是 `false`。贴进 GKD 以后不会马上点屏幕。确认这是家人专用平板后，再手动把规则打开。打开之后会接听所有微信语音/视频，GKD 这里没有联系人名单。只想接某几个人时，用主脚本的 `ALLOW_CALLER_NAMES`，并保持 GKD 关闭。

打开之后，GKD 也只在这些情况下点：

- 同一画面里既有「接听」，又有「挂断」或「拒绝」
- 较短的「邀请你视频通话」「邀请你语音通话」
- 已经点过接听之后，只点「扬声器已关」

看得见「发送」就不点。不点单独的「视频通话」，也不把「取消」当成来电。同一次界面里接听最多点两次，离开这个界面后才会重新计数。横幅规则另外有大约 20 秒的匹配时间，用来少去点聊天里的同样字样。横幅没点开时，主脚本仍会自己打开微信。

## 安装

1. 从官网正式版下载：<https://gkd.li/guide/> 或 <https://github.com/gkd-kit/gkd/releases>（`gkd-v*.apk`）
2. 不要装应用市场里的「增强版 / 黄金版」
3. 允许未知来源后安装，打开 **无障碍**
4. 开关灰色时：应用信息 → 高级设置 → **允许受限制的设置**，再开无障碍
5. 首页打开 **常驻通知**，并给 GKD 做和微信一样的[小米保活](xiaomi.md)

## 导入规则

本仓库 `gkd/`：

| 文件 | 贴到哪里 |
| --- | --- |
| `wechat-auto-answer.json5` | 能添加整份订阅时用 |
| `app-rule-wechat.json5` | **添加应用规则**（平板上往往只有这一项） |
| `global-incoming-banner.json5` | **添加全局规则**（用来点桌面/通知栏上的邀请横幅） |

若列表里已经有「微信」应用规则，先删再贴新的。贴进去时规则是关的。确认这是专用平板后，再打开「自动接听语音和视频」。需要点桌面横幅时，再打开「点微信来电横幅」。

打开之后会接听所有微信语音/视频。只接某一个家人时，用主脚本的名单，不要把真实昵称写进规则再提交回仓库。一定要在自己平板上改选择器的话，改完只留在平板里。

## 和 AutoJs6 小窗脚本配合（旧方案）

`autox/open-wechat-on-call.js` 只负责把微信拉到前台/小窗，接听仍交给 GKD。它的 `ENABLED` 出厂是 `false`，不改就不会打开微信。现在已被 `auto-answer-fullscreen.js` 替代，一般不必再装。
