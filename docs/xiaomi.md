# 小米平板：权限与保活

在**老人那台小米平板**上做，不要改你自己日常用的手机。下面这些权限会让脚本能点屏幕，所以不要在日常手机上开同一套。菜单名字因 MIUI / 澎湃 OS 会差一点，找不到就在设置顶部搜索。

AutoJs6（或你打包出来的「微信接听」）和**微信**都要设。只设一边，过几分钟就可能接不了。

## 微信：来电要弹得出来

GKD 或脚本要点的是屏幕上已经出现的按钮。微信被切到后台、小米又不准它弹全屏时，屏幕上没有「接听」。

设置搜索，微信全部打开：

1. **后台弹出界面** → 始终允许
2. **显示悬浮窗** → 始终允许
3. **锁屏显示** → 允许
4. 通知：允许通知、悬浮通知/横幅、锁屏通知；若有「微信电话 / 语音视频」，重要性调到最高

微信 → 我 → 设置：

- 打开「关怀模式」（字大、按钮大）
- 新消息通知：打开
- 接收语音和视频通话邀请提醒：打开
- 通知显示消息详情：打开

最近任务里**锁定微信**，不要上滑清掉。自启动打开，省电策略选 **无限制**。

## AutoJs6（或打包应用）

同样搜索：

- **自启动**：开
- **省电策略**：无限制（不要智能限制）
- **后台弹出界面**：始终允许
- **显示悬浮窗**：允许
- 最近任务里锁定
- **无障碍**保持打开（小米重启后有时会关）
- **通知使用权 / 通知监听**保持打开

系统电池页关掉省电模式、超级省电。

无障碍开关是灰的，或提示「受限制的设置」：

1. 长按 AutoJs6 图标 → 应用信息 → 高级设置
2. 打开「允许受限制的设置」
3. 再去无障碍里打开

## 屏幕尽量亮着

息屏时，微信有时只出一条小横幅，自动点接听会失败。家庭专用平板建议：

1. **屏幕超时**改成 10 分钟或「永不」
2. 打开「充电时屏幕不休眠 / 充电时保持亮屏」
3. 平板长期插着充电器，放在老人够得着、摄像头对着人的地方
4. 能不用复杂锁屏密码就不用（这是家里专用机）

锁屏有 PIN/图案时，脚本通常**不能**替你解锁。
