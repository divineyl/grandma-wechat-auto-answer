# 不会自动接听时对照

先确认跑的是改过开关的 `auto-answer-fullscreen.js`，平板停在**桌面**再打测试电话。开关、名单和「不会点什么」见 [SECURITY.md](../SECURITY.md)。

## 先看屏幕上的提示

| 提示 | 原因 | 怎么办 |
| --- | --- | --- |
| 自动接听未开启 | 开关还是 `false` | 改成 `true`，停止旧脚本，再运行 |
| 必须写成 true 或 false | 写成了 `"true"` | 去掉引号 |
| 接听名单写错了 | 名单不是列表 | 写成 `[]` 或 `["妈妈"]` |
| 将接听所有微信来电 | 名单是空的 | 专用平板可以留。这不是你的日常手机时，改回 `false` |
| 不在接听名单里 | 通知里没有名单上的名字 | 名字要和通知标题一致。聊天列表里的同名不算。填了名单就必须打开通知使用权 |
| 看见发送按钮 | 屏幕上有「发送」 | 收起键盘。这次故意不点 |
| 已有一份接听脚本在运行 | 旧脚本还在 | 先停止，再运行新的。改完开关却仍不接，多半是这个 |
| 检测到微信来电，但仍不接 | 画面上没有同时出现「接听」和「挂断」或「拒绝」，或这一屏已经点过两次 | 脚本不按位置猜按钮。截一张来电画面发到 Issue（头像打码） |
| 无障碍被关掉了 | 小米把无障碍关了 | 重新打开，再运行脚本 |

同一次来电画面里，接听或邀请横幅最多点两次，然后停手，直到这个画面消失。这是为了避免一直点下去，点到挂断或发送。

下面这些情况脚本会故意不做：

- 聊天或通知里只出现「视频通话」「语音通话」，没有「邀请你视频通话」或「邀请你语音通话」
- 文案里有「未接」「已结束」「已取消」「已拒绝」「已挂断」「通话时长」
- 微信是英文界面（不认识 Answer / Send，也就不会去点）
- 来电按钮上没有「接听」这几个字

## 1. 脚本还在不在跑

1. AutoJs6 里这条脚本必须显示**正在运行**（不要被音量键停掉）。
2. 设置 → 无障碍 → AutoJs6 **开着**。打测试电话前再看一眼，小米有时会关。
3. 设置搜索 **通知使用权** / **通知监听**：AutoJs6 先关掉再打开，然后回 AutoJs6 **重新运行**脚本。
4. 设置搜索 **后台弹出界面**：AutoJs6、微信都选始终允许。

## 2. 看有没有「检测到微信来电」

打过来时应弹出「检测到微信来电，正在接听」。没有这句，而只有「未开启」或「名单」那类提示时，先看上面的表，不要继续改权限。

- **没有这句**：通知没监听到。重点做通知使用权、微信横幅/锁屏通知、后台弹出。
- **有这句但仍不接**：来电画面上没有同时出现「接听」和「挂断」或「拒绝」，或这一屏已经点过两次。脚本不会按位置猜。把来电那一屏截图发到 GitHub Issue（打码家人头像即可）。

锁屏有密码时先把屏幕亮着、停在桌面再试。

## 3. 重启后必须重新点运行

这是正常的，不是脚本坏了。按 [keep-running.md](keep-running.md) 设定时任务和开机启动。

## 4. 只有通知、没有大接听按钮

微信没被允许从后台弹全屏。按 [xiaomi.md](xiaomi.md) 打开微信的后台弹出界面、悬浮窗、横幅通知，并锁定最近任务。

## 5. 过几分钟就失效

省电策略不是无限制，或最近任务没锁。AutoJs6 打开前台服务。

## 6. 点了接听但没声音

平板音量；通话界面里扬声器是否仍显示「已关」。脚本会尝试点「扬声器已关」。

## 7. 陌生人打来也会接

只有开关已经改成 `true` 并且名单还是 `[]` 时，才会这样。家庭专用机可以接受。日常手机会接到不认识的人，请保持 `false`，或写上名单。

GKD 的接听规则一旦打开，也会接所有来电，而且没有名单。不要和主脚本一起开。

## 8. 仍可能失败

- 微信改版后面按钮文案变了
- 平板厂商把无障碍点按做得很严
- 来电出现在系统小岛/胶囊里，而不是微信自己的界面
