# 离家前自测

每条都要打通。哪条失败，先看 [troubleshooting.md](troubleshooting.md)，不要假设「应该可以」。

测试时你坐在另一间房间或用自己的手机，平板放在老人平时会坐的位置。

先完成 [getting-started.md](getting-started.md) 和 [keep-running.md](keep-running.md)。安全边界见 [SECURITY.md](../SECURITY.md)。

## 出门前先看开关

- [ ] 这是老人的专用平板，不是你每天用的手机
- [ ] 脚本提示是「将接听所有微信来电」或「只接听名单中的联系人」，不是「自动接听未开启」
- [ ] 如果提示是「将接听所有微信来电」，你接受陌生人打来也会接
- [ ] 如果用了名单，你用名单里的人、再用一个不在名单里的号各打一次。后者必须不接
- [ ] GKD 的接听规则是关的。只留 AutoJs6 这一套在点
- [ ] 平板没有停在带「发送」按钮的聊天输入框上

## 测试 1：屏幕亮着、停在桌面

- [ ] 平板亮着，回到桌面（不要停在微信聊天里）
- [ ] AutoJs6 脚本显示正在运行
- [ ] 你打微信视频
- [ ] 大约一两秒内自动点接听
- [ ] 能听到扬声器声音，老人不用碰平板

## 测试 2：屏幕熄灭

- [ ] 等平板自己息屏（或按电源键息屏）
- [ ] 再打一次微信视频
- [ ] 能自动接，或至少亮屏后自动接

不过：把屏幕超时调长，打开充电时保持亮屏，平板插着电。

## 测试 3：锁屏

- [ ] 锁上屏幕
- [ ] 再打一次
- [ ] 能自动接

不过：家庭专用机可关掉复杂锁屏，或把自动锁屏调到很长。

## 测试 4：过 10 分钟再打

- [ ] 平板放着别动，过 10 分钟
- [ ] 再打一次视频
- [ ] 仍然自动接

不过：AutoJs6 和微信的自启动、省电无限制、最近任务加锁。小米最常在这一步杀后台。

## 测试 5：重启平板（确认「永久生效」）

- [ ] **不要**手动点运行
- [ ] 重启平板并解锁
- [ ] 等约 1 分钟，通知栏里 AutoJs6（或打包应用）还在
- [ ] 无障碍、通知监听仍是开的
- [ ] 最近任务里重新锁定微信和 AutoJs6
- [ ] 再打一次视频

不过：回头做 keep-running 和小米自启动。重启后无障碍被关是小米常见行为。

## 出门当天再确认

- [ ] 充电器插好
- [ ] 平板音量开到最大或接近最大
- [ ] 摄像头没被布挡住
- [ ] 微信已登录，能收到你的消息
- [ ] AutoJs6 无障碍是开的
- [ ] 你用自己的手机再打通一次，再出门
