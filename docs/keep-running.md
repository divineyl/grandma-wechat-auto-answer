# 让接听脚本一直生效（不用每次点运行）

脚本本身不会在点「停止」或关机后自己复活。要靠 AutoJs6 的**定时任务 + 小米自启动**。设一次即可。

先保证 `auto-answer-fullscreen.js` 能手动运行并接听，再做下面这些。

## 1. 设为开机和打开软件时自动跑

在 AutoJs6 文件列表里：

1. **长按** `auto-answer-fullscreen.js`（或先导入 `boot-start.js` 再长按它）
2. 选 **定时任务**（有的版本在「更多」里）
3. 添加一条：**广播触发** → **AutoJs6 启动时**
4. 再添加一条：**广播触发** → **开机**（`BOOT_COMPLETED` / 开机完成）
5. 如果能填延迟，开机那条设 **30 秒**（等无障碍起来）

这样以后打开 AutoJs6，或平板重启并解锁后，脚本会自己起来，不必再点运行。

`boot-start.js` 会检查主脚本是否已在运行，避免开两份。

## 2. 让 AutoJs6 自己会开机

AutoJs6 里打开 **设置**：

- **开机启动**（或自动启动服务）打开
- 有 **前台服务 / 稳定模式** 也打开（通知栏会一直留着 AutoJs6，这是好事）

系统设置见 [xiaomi.md](xiaomi.md)。小米不给自启动时，重启后 AutoJs6 不会起来，定时任务也就不会跑。

## 3. 更省事：打包成独立应用（可选）

不想让家里桌面上出现 AutoJs6、也不想进软件点运行：

1. AutoJs6 里选中 `auto-answer-fullscreen.js` → **打包**
2. 应用名可填「奶奶接听」
3. 打开 **开机自启动**
4. 打开 **前台服务**（后台不容易被杀）
5. 生成 APK，安装这个新应用
6. 无障碍、通知使用权、自启动、无限制电量，都改给**这个新应用**，不再依赖 AutoJs6 主程序

打包出的应用第一次仍要开权限；之后开机即可。

不要把打包 APK 提交进本仓库。

## 4. 怎么确认已经一直生效

1. 不要手动点运行，把平板重启，解锁
2. 等大约 1 分钟，通知栏应有 AutoJs6（或「奶奶接听」）在跑
3. 用你的手机打微信视频，应仍会自动接

通知栏没有、脚本列表里也不是运行中：回头做第 2 步和小米自启动。
